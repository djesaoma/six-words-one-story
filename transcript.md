# Build transcript — Six Words, One Story

## Prompt
Write 15 different six-word stories. Each story must be exactly 6 words.
Make them varied: some funny, some sad, some surprising, some sci-fi, some romantic.
Each story should be a complete mini-story with a beginning and twist.

## Model
deepseek-v4.1-flash-free via 100milionseek (free API, 100M tokens/day).

## Selected story
"She sold his ring. Bought freedom."
- She(1) sold(2) his(3) ring(4). Bought(5) freedom(6). = 6 words.
- Arc: oppression to liberation; a complete story with a twist.

## Program
main.py writes the story to /output/entry.txt when run in the sandbox.
